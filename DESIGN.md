# Design System: Clear Ledger

## Overview
**Clear Ledger** is a minimalist and modern corporate design system optimized for financial clarity and reduced cognitive load. The aesthetic is disciplined, transparent, and quietly supportive, serving as a neutral canvas for financial data.

## Visual Strategy
- **Minimalism:** Focus on high-quality whitespace and precise alignment.
- **Quiet Authority:** Uses asymmetrical layouts and overlapping elements to guide the eye.
- **Tonal Depth:** Favor tonal layers and ambient depth over heavy drop shadows.

## Layout & Spacing
- **Grid:** 12-column grid, 1200px max-width, 24px gutters.
- **Rhythm:** 8pt linear scale (Base: 4px).
- **Density:** Comfortable density to allow whitespace to breathe.

## Components
- **Buttons:** Primary (Slate/Blue bg), Secondary (Light Gray bg). 8px radius.
- **Cards:** White with 1px soft gray border or ambient shadow. 12px radius.
- **Inputs:** 1px border (#E5E7EB), shifting to Blue on focus. Labels above input.
- **Data Lists:** 16px vertical padding, thin dividers.
